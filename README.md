# Hot Pot Express - Веб-приложение для заказа корейского рамена

## Описание проекта

Hot Pot Express - это веб-приложение для заказа еды из корейской библиотеки раменов, разработанное в рамках курсовой работы. Приложение предоставляет пользователям возможность просматривать меню, добавлять товары в корзину, оформлять заказы и отслеживать их статус.

## Основные функции

### Для пользователей:
- **Регистрация и авторизация** - система аутентификации пользователей
- **Просмотр меню** - каталог товаров с фильтрацией по категориям
- **Поиск товаров** - функция поиска по названию и описанию
- **Корзина** - добавление/удаление товаров, изменение количества
- **Оформление заказов** - создание заказа с указанием адреса доставки
- **История заказов** - просмотр предыдущих заказов и их статусов
- **Профиль пользователя** - управление личными данными и сменой пароля

### Для администраторов:
- **Управление товарами** - добавление, редактирование и удаление товаров
- **Управление категориями** - создание и редактирование категорий товаров
- **Управление заказами** - просмотр и изменение статусов заказов
- **Просмотр деталей заказов** - подробная информация о каждом заказе

## Технологии

- **Backend**: ASP.NET Web Forms (C#)
- **База данных**: Microsoft SQL Server
- **Frontend**: HTML5, CSS3, JavaScript
- **Стилизация**: Custom CSS с использованием Font Awesome и Google Fonts
- **Вспомогательные библиотеки**: SweetAlert2 для уведомлений

## Структура проекта

### Основные страницы:
- `index.aspx` - главная страница с каталогом товаров
- `UserProfile.aspx` - профиль пользователя
- `cart.aspx` - корзина товаров
- `orders.aspx` - история заказов
- `admin.aspx` - панель администратора

### База данных:
Проект использует базу данных SQL Server с следующими основными таблицами:
- `users` - данные пользователей
- `userData` - дополнительная информация о пользователях
- `goods` - товары
- `categories` - категории товаров
- `cart` - корзины пользователей
- `orders` - заказы
- `orderItems` - товары в заказах

## Установка и запуск

### Предварительные требования:
- Microsoft SQL Server
- .NET Framework
- IIS Express или полноценный IIS

### Шаги для запуска:
1. Клонируйте репозиторий проекта
2. Восстановите базу данных из файла `db_tp_cw` (скрипты находятся в папке Database)
3. Настройте строку подключения в файле `Web.config`
4. Запустите проект через Visual Studio или опубликуйте на IIS

### Учетные данные по умолчанию:
- **Администратор**: email: `admin`, пароль: `admin`
- **Обычный пользователь**: требуется регистрация через интерфейс приложения

## Особенности реализации

### Безопасность:
- Пароли хранятся в виде хэшей SHA256
- Проверка авторизации на всех защищенных страницах
- Защита от SQL-инъекций через параметризованные запросы

### Пользовательский интерфейс:
- Адаптивный дизайн
- Интуитивная навигация
- Модальные окна для авторизации и действий с заказами
- Визуальные уведомления через SweetAlert2

### Функциональность администратора:
- MultiView для переключения между разделами
- CRUD операции для товаров и категорий
- Управление статусами заказов
- Просмотр детальной информации о заказах

## Дополнительные возможности

- Поиск товаров в реальном времени
- Фильтрация товаров по категориям
- Валидация данных на стороне клиента и сервера
- Транзакции при оформлении заказов для обеспечения целостности данных
- Проверка наличия товаров на складе
